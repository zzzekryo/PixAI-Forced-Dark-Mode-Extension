# PixAI Forced Dark Mode Extension

A lightweight browser extension that forces strict dark mode on PixAI without modifying generated images.

## Features

* Forces dark mode on the PixAI website.
* Does not modify generated images.
* Lightweight CSS-based implementation.
* No unnecessary permissions or background scripts.

## Installation

### Manual Installation

1. Download or clone this repository.
2. Extract the ZIP file if necessary.
3. Open your browser's extension management page:

   * Chrome: `chrome://extensions`
   * Microsoft Edge: `edge://extensions`
   * Opera: `opera://extensions`
4. Enable Developer Mode.
5. Click "Load unpacked".
6. Select the folder containing `manifest.json`.

The extension should now be installed.

## Compatibility

Designed for PixAI (`https://pixai.art/`) and Chromium-based browsers that support Manifest V3.
